

# Datos recopilados

### Datos de usuarios (Person)
- Nombre completo.
- Edad y género.
- Correo electrónico y número de teléfono.
- Documento Personal de Identificación (DPI).
- Licencia de conducir (para conductores).
- Contraseña encriptada.
- Fotografías (perfil, DPI, licencia).

### Datos de vehículos (Vehicle)
- Placa del vehículo.
- Modelo, marca, línea y color.
- Categoría del vehículo.

### Datos de rutas (Route y Stand)
- Punto de inicio y destino.
- Puntos intermedios (paradas).
- Fecha y hora de salida.
- Asientos disponibles.
- Coordenadas de ubicación (geolocalización).

### Datos de viajes (Trip)
- Identificador del viaje.
- Estado del viaje (pendiente, aceptado, completado).
- Hora de inicio y fin.
- Precio acordado entre conductor y pasajero.

### Datos de calificaciones (Rating)
- Puntuación numérica.
- Comentarios del usuario.
- Historial de interacciones entre pasajeros

## Uso
- Registro y autenticación de usuarios.
- Coordinación de rutas y viajes.
- Construcción de confianza en la comunidad.

## Seguridad
- Verificación documental manual por administradores.
- Bucket e instancia Google Cloud SQL para almacenamiento seguro de imágenes e informacion.

## Declaración
Los datos solo se usan para mejorar la seguridad y funcionamiento de la plataforma. No se comparten con terceros sin consentimiento.
