# Política de Privacidad de MovilizaGT


En **MovilizaGT**, se respeta y potege la privacidad de los usuarios.  
Esta política explica cómo e recopilan, usan y protege la información personal cuando se usa la aplicación.

---

## 1. Información que se recopila

### 1.1 Datos de usuario
- Nombre completo.
- Edad y género.
- Correo electrónico y número de teléfono.
- Documento Personal de Identificación (DPI: frente y dorso).
- Licencia de conducir (frente y dorso, para conductores).
- Fotografía de perfil.

### 1.2 Datos de vehículos
- Placa.
- Marca, línea, modelo, color y categoría.

### 1.3 Datos de uso de la aplicación
- Rutas creadas y buscadas.
- Puntos de origen, destino y paradas.
- Viajes solicitados, ofrecidos y completados.
- Calificaciones y comentarios entre usuarios.

### 1.4 Datos técnicos
- Ubicación GPS en tiempo real (para coincidencia de rutas).
- Dirección IP y datos de conexión.
- Historial básico de interacciones en la app.

---

## 2. Uso de la información
La información recopilada se utiliza únicamente para:
- Autenticar y verificar la identidad de usuarios.
- Publicar y coordinar rutas y viajes.
- Asociar vehículos con conductores verificados.
- Mejorar la seguridad de la comunidad mediante calificaciones.
- Enviar notificaciones relacionadas con viajes y coincidencias.
- Cumplir con requisitos legales y de seguridad.

**No se usan los datos para fines publicitarios sin consentimiento previo.**

---

## 3. Almacenamiento y seguridad
- Los documentos y fotos se almacenan de forma segura en **Bucket de Google Cloud**.
- La base de datos **MySQL** encripta datos sensibles.
- La comunicación entre cliente y servidor se realiza bajo **HTTPS/TLS**.
- El administrador realiza una **verificación documental manual** antes de habilitar un perfil.

---

## 4. Compartición de información
- **No se comparten datos personales con terceros**, salvo que:
  - Lo exija la ley o una autoridad competente.
  - Sea necesario para proteger la seguridad de los usuario
