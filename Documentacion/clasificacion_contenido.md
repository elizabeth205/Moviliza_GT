# Clasificación de Contenido

## Público
MovilizaGT está destinada exclusivamente a **usuarios mayores de edad (18+)**, ya que la plataforma requiere verificación documental como parte de las medidas de seguridad.  
Esto incluye:  
- Documento Personal de Identificación (DPI) para pasajeros.  
- Licencia de conducir para los conductores.  

Los usuarios al descargar la aplicación aceptan expresamente el **proceso de verificación de identidad** al registrarse, como requisito indispensable para usar la aplicación.  

## Contenido
- No contiene violencia, drogas, ni contenido sexual.  
- No incluye elementos gráficos ofensivos ni inapropiados.  
- Todo el contenido se limita a la gestión de transporte compartido y comunicación entre usuarios verificados.  

## Seguridad y Restricciones
- **Usuarios menores de edad no pueden registrarse ni utilizar la aplicación.**  
- El registro está condicionado a la **aceptación de la verificación de identidad**.  
- Los datos de identificación se almacenan de forma segura y son utilizados únicamente para la validación de perfiles dentro de la comunidad.  

## Clasificación sugerida
**Apta únicamente para mayores de 18 años.**
